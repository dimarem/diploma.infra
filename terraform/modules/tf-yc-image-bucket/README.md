# Модуль для создания бакета хранения изображений

Использует провайдер `yandex-cloud/yandex` версии `>= 0.87.0`.

**Принимает следующие параметры:**

- `image_bucket_name`. Наименование бакета для хранения изображений. Тип `string`.
- `image_bucket_size`. Размер бакета для хранения изображений в байтах. Тип `number`. Значение по умолчанию: `1073741824`.
- `folder_id`. ID директории в облаке. Тип `string`.
